# Recursos locales

- **Barlow**: fuente de The Barlow Project Authors bajo SIL Open Font License 1.1, en los pesos 400, 500, 600 y 700 (`fonts/`). Se conserva la licencia en `fonts/OFL-Barlow.txt`. Se sirve desde la API porque la política de seguridad de contenido solo admite fuentes del mismo origen.
- **gym.jpg**: fotografía de George Pagan III, [Gym equipment with weights and machines](https://unsplash.com/photos/gym-equipment-with-weights-and-machines-UpJkZIv4fM4), publicada el 4 de enero de 2026 y ofrecida bajo la [licencia Unsplash](https://unsplash.com/license). Se descargó una versión de 1600 píxeles para el fondo del acceso. La página sirve el archivo local; no envía solicitudes a Unsplash desde el navegador.

El fondo es una fotografía alternativa al recurso del prototipo. Las capturas del prototipo de Figma se usan como referencia visual y no se insertan como pantallas dentro de la interfaz.

- **classes/**: una fotografía por disciplina (`yoga.jpg`, `spinning.jpg`, `crossfit.jpg`, `zumba.jpg`, `trx.jpg`, `estiramiento.jpg`), aportadas por el equipo para las tarjetas del catálogo y redimensionadas a un máximo de 900 píxeles de ancho. Las clases de una categoría sin fotografía propia usan `gym.jpg`.
